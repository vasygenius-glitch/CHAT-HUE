Как запустить программу (Инструкция)

Вариант 1 (Если у вас уже есть Python):
1. Откройте командную строку в этой папке.
2. Введите команду: pip install PyQt6 beautifulsoup4 python-docx rapidfuzz PyMuPDF
3. Запустите программу командой: python main.py

Вариант 2 (Если вы хотите создать .exe файл, чтобы запускать двойным кликом):
1. Убедитесь, что у вас установлен Python (при установке обязательно поставьте галочку "Add Python to PATH").
2. Просто дважды кликните по файлу build_exe.bat.
3. Скрипт сам скачает нужные библиотеки и соберет программу.
4. Когда скрипт закончит работу, зайдите в появившуюся папку dist, затем в папку FuzzySearch.
5. Там будет лежать файл FuzzySearch.exe (теперь с красивой иконкой лупы!) - это и есть ваша готовая программа. Можете вынести ярлык на рабочий стол!
